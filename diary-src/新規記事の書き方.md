# Diary 記事の追加・修正のしかた

記事は **1記事 = 1ファイル** です。`diary-src/` に置いたファイルから、`build.py` が
記事ページ（`/diary/記事名/`）・Diary一覧（`/diary/`）・トップのDiaryタブ・`sitemap.xml` をまとめて作ります。
`index.html` のDiary部分は直接編集しないでください（ビルドで上書きされます）。

## 新しい記事を書く

1. `diary-src/_template.html` をコピーして、`2026-10-01-記事名.html` のような名前で保存する
   （日付は並び順には使わないので、ファイル名は自由です。先頭に `_` を付けるとビルド対象外になります）
2. 先頭の設定ブロックを埋める

   | 項目 | 内容 |
   |---|---|
   | `title` | 記事タイトル |
   | `date` | `2026-10-01` の形式 |
   | `category` | `diary`（日記）/ `cg` / `hobby1`（デジタルな趣味）/ `hobby2`（アナログな趣味） |
   | `slug` | URLになる英単語。半角の小文字・数字・ハイフンだけ。例: `kiosk-3-case` → `/diary/kiosk-3-case/` |
   | `description` | 一覧・検索結果に出る説明文（1〜2文） |
   | `order` | 省略可。同じ日付の記事の並び順（数字が大きいほど上） |
   | `draft` | `true` にすると公開されません（書きかけ用）。公開するときはこの行を消す |

3. 設定ブロックの下に本文をHTMLで書く。見出しは `<h2>` と `<h3>`、段落は `<p>`、
   箇条書きは `<ul><li>`、表は `<table>`、強調は `<strong>` が使えます
4. ターミナルで `python3 build.py` を実行する
5. 変更されたファイルをpushする（`diary/` フォルダ、`diary-src/` フォルダ、`index.html`、`sitemap.xml`）

画像や動画は `diary/` 直下に置いて、本文では `/diary/ファイル名` と**先頭にスラッシュを付けて**指定します。
例: `<img src="/diary/photo.jpg" alt="説明">`

## 記事を直す・消す

- 直す: `diary-src/` のファイルを編集して `python3 build.py`
- 消す: `diary-src/` のファイルを削除して `python3 build.py`（`diary/記事名/` も自動で消えます）
- 一時的に非公開にする: 設定ブロックに `draft: true` を足して `python3 build.py`

## 公開前のチェック

「（記事タイトルをここに）」などテンプレの文言が残っていると、ビルドがエラーで止まります。
